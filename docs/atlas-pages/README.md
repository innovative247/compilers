# Atlas page drafts

These are working drafts of the compilers' customer-facing Atlas help pages, moved here from
the team handbook (`.docs/unit-test/compilers/`) — product-specific material belongs in the
product's own repo, not the shared handbook.

- `atlas-page-draft.md` — draft of the "Getting Started with the Compilers" page.
- `atlas-review/` — HTML exports of the published/in-review Atlas pages (Getting Started,
  Windows Setup, Ubuntu Setup, Source Code) captured for offline review/diffing.

The pages actually live on Atlas at
https://support.innovative247.com/help/Developer-Tools/Compilers — these files are drafts,
not the source of truth. Edit and publish through Atlas directly; update these copies only
when you want a local record of what was reviewed.
