Windows Setup

Prerequisites

  • Windows 10 / 11 / Server 2022 with PowerShell 5.1+ (Windows Terminal recommended)
  • Git for Windows — verify with git --version
  • An Innovative-authorized GitHub account
  • A working copy of the SBN_IR SVN tree — follow Source Code first

Step 1 — Install the compilers

From PowerShell:

irm https://raw.githubusercontent.com/innovative247/compilers/main/install.ps1 | iex

The installer downloads the latest release into %LOCALAPPDATA%\ibs-compilers and offers to remove any pre-existing Python ibs_compilers install.

Step 2 — Configure

Open a fresh PowerShell window so the new PATH entry loads, then:

set_profile configure   # Adds compilers to PATH; verifies the install
set_profile             # Wizard — add a database connection profile
runsql version          # Smoke test

Use any profile name (e.g. SBNA). Point SQL_SOURCE at the SVN working copy you set up via Source Code (typically $HOME\ir_local).

Notes

  • Clipboard stops working over RDP: from cmd.exe, taskkill /f /im rdpclip.exe & rdpclip.exe
  • Command not found after install: open a new terminal — PATH changes don't apply to existing sessions.
