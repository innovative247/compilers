Source Code (SBN_IR)

The SBN_IR repository is the SVN tree that holds every piece of SQL, JAM source, options, table-locations, actions, and message data the Innovative compilers operate on. The Compilers expect a working copy of this repo on disk and reference it as $ir.

Repository Access

The SVN repository lives on Innovative's private network and is not publicly reachable. To get the URL:

  1. Contact your Innovative point of contact (account manager, Innovative SR, or onboarding engineer).
  2. Request the SBN_IR SVN URL.
  3. You will be provided a URL of the form http://<host>/work2/svn/repos/SBN_IR/trunk.

Substitute the URL for <url> in the commands below.

Initial Checkout

Windows

Prerequisites: a Subversion command-line client (e.g. SlikSVN) on your PATH.

mkdir $HOME\ir_local
cd $HOME\ir_local
svn checkout <url> .

Ubuntu (native or WSL)

Prerequisites: subversion installed (sudo apt install subversion if not).

mkdir -p ~/ir_local
cd ~/ir_local
svn checkout <url> .

Set the $ir Environment Variable

The compilers reference your working copy as $ir. Setting it once means every $ir/... path in scripts and documentation just works.

Windows (PowerShell)

[Environment]::SetEnvironmentVariable("ir", "$HOME\ir_local", "User")

Restart your terminal for the change to take effect.

Ubuntu

echo 'export ir="$HOME/ir_local"' >> ~/.bashrc
source ~/.bashrc

Updating

To pull the latest changes from the SVN server:

cd $ir
svn update

SVN merges any upstream changes into your working copy. If you have local edits and they conflict with upstream, SVN reports the conflicted paths — resolve them per the standard SVN conflict workflow, then re-run svn update.

What's in the Repo

Top-level folders (from a fresh checkout):

  • css/ — SQL source organized by application module (ss/ba/, ss/bl/, etc.) plus setup/ for options, table-locations, actions, messages.
  • ibs/ — IBS application-layer SQL and configuration.
  • ios/ — IBS Unix toolchain (Command Library, Terminal Definitions, etc.).
  • create_links.sh — legacy script that creates lowercase symlinks on Unix systems. Modern checkouts already use lowercase folder names; this script is a historical artifact.

Used By

The Compilers (Compilers → Getting Started) read this working copy via the SQL_SOURCE field in each profile in settings.json. Set SQL_SOURCE to the same path you assigned to $ir above.

For installing and configuring the compilers themselves, see Compilers → Getting Started.
