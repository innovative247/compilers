Ubuntu Setup

Prerequisites

  • Ubuntu (native Linux or WSL) with your username configured
  • git, curl — verify with git --version / curl --version
  • An Innovative-authorized GitHub account
  • A working copy of the SBN_IR SVN tree — follow Source Code first

Step 1 — Install the compilers

curl -fsSL https://raw.githubusercontent.com/innovative247/compilers/main/install.sh | bash

The installer downloads the latest release into ~/ibs-compilers and adds the directory to your PATH via ~/.bashrc.

📷 Screenshot placeholder — install.sh final output

Step 2 — Configure

Open a new shell so the new PATH entry loads, then:

set_profile configure   # Verifies the install, adds compilers to PATH
set_profile             # Wizard — add a database connection profile
runsql version          # Smoke test

Use any profile name (e.g. SBNA). Point SQL_SOURCE at the SVN working copy you set up via Source Code (typically ~/ir_local).

Notes

  • Permission denied after self-update: chmod +x ~/ibs-compilers/*
  • Bash hash cache: hash -r after PATH changes.
